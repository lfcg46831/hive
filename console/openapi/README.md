# OpenAPI document

`v1.json` is the published public API document exported from the running `Hive.Api`
host. It is a build artifact, not source: it is git-ignored and regenerated by the
`PublicApiOpenApiSnapshotTests` snapshot test.

```bash
dotnet test tests/Hive.Tests --filter PublicApiOpenApiSnapshotTests
npm --prefix console run verify:contracts
```

The parity check fails when the file is missing, so contract verification always runs
against a document exported from the current backend, never against a stale copy.
